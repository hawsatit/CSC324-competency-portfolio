# Advanced Competency 1: Design

**Artifact:** The website design

## Context and purpose

I used the principles of interaction design to create effective user interfaces.

## Evidence of advanced mastery

I used the Gestalt principles:

- **Proximity:** Spacing makes it clear which items belong to the same group. E.g., on the buildings page, each dorm cluster is separated by a larger space, each dorm by a smaller space, and each room within a building by an even smaller space.
- **Similarity:** Each color has the same meaning: recycle is green, redeem is blue, batteries is orange. All cards, chips, and badges of one kind look the same.
- **Common fate:** Each result card, building area, and the center's layout fades in as one unit.
- **Continuity:** The navbar logo, page headings, and cards are aligned on the left, so the eye runs straight down the page.
- **Closure:** Each campus area on the buildings page has a single line on its left side, not a full box. The eye completes it into a region.
- **Figure/ground:** White cards with soft shadows sit on the warm tinted background, so they read clearly as objects.
- **Symmetry:** The home page is centered with two equal cards, and building cards in a row are equal width and height.
