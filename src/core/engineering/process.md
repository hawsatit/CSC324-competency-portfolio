# 4.3 Process

**Artifact:** Our [GitHub project board](https://github.com/orgs/grinnell-csc324-fall-2026/projects/4)

## Context and purpose

- We used the GitHub project board to put down our goals.

## Evidence of mastery

- We put down the tasks we wanted to do, were working on, and completed.
- We get an email notification every time something is resolved.
- We were also able to see the issues that arise, and ways to work around them (commands to run).

## My contribution

I put down the tasks I wanted to do and also saw what others were working on.

## Reflection

I've never really worked with a team on a long-term project, or used GitHub features to this extent, so this was very helpful for me. I found the project board very helpful because it allowed everyone to see what needed to be done without constantly asking each other for updates. I also liked how we could document problems and solutions so that other team members could refer to them if they encountered similar issues. I can see how tools like this would be especially useful in larger software development teams, where many people are working on different parts of a project at the same time.
