## Reflection

I thought this was really cool because instead of relying on an IDE to implement the website, we were able to just host the website locally for development. This allowed us to see exactly how the website would look when we actually host it on a real server. By combining all parts (frontend, backend, database), we were also able to test that everything is connected and that we can do API calls and get the results we want displayed the way we wanted. This allowed us to get the MVP we wanted.
